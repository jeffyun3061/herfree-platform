# Herfree 운영자 매뉴얼

이 문서는 개발자가 아닌 서비스 운영자가 Herfree를 안전하게 관리하기 위한 최소 절차입니다.

## 운영자가 매일 확인할 것

| 항목 | 확인 위치 | 조치 |
|------|-----------|------|
| 신규 신고 | 관리자 > 신고 관리 | 명백한 광고·개인정보 노출·공격성 글은 숨김 처리 |
| 문의/비공개 상담 답변 | 관리자/운영자 계정 | 본인 글 또는 운영자 범위에서만 확인 |
| 로그인/비밀번호 재설정 장애 | 서버 로그/CloudWatch | SMTP 실패가 반복되면 개발자에게 전달 |
| 이미지 업로드 장애 | 서버 로그/CloudWatch | S3 권한·버킷·용량 이슈 확인 요청 |

## 운영자가 해도 되는 작업

- 신고된 게시글/댓글 숨김 또는 복구
- 사용자 계정 정지/해제
- 부적절 닉네임 초기화
- 공지 등록/수정
- 개인정보 삭제 요청을 개발자에게 전달

## 운영자가 직접 하면 안 되는 작업

- AWS root 계정으로 일상 운영
- DB 직접 수정
- `.env.prod` 임의 수정
- S3 버킷 퍼블릭 쓰기/읽기 정책 변경
- 관리자 권한을 본인 판단으로 추가 발급

## 사용자 문의 대응

### 비밀번호 재설정 메일이 오지 않음

1. 스팸함 확인을 안내한다.
2. 같은 이메일로 5분 뒤 다시 요청하게 한다.
3. 여러 사용자에게 동시에 발생하면 SMTP 장애로 보고 개발자에게 전달한다.

운영 로그에는 재설정 URL이나 토큰이 남지 않아야 한다. 운영자가 토큰을 요구하거나 전달하면 안 된다.

### 계정 정지 문의

1. 관리자 화면에서 계정 상태와 사유를 확인한다.
2. 정지 해제는 운영 정책에 맞을 때만 처리한다.
3. 정지/해제 작업은 감사 로그에 남는다.

### 개인정보 삭제 요청

1. 요청자의 계정 식별 정보를 확인한다.
2. 개발자에게 삭제/익명화 처리 요청을 전달한다.
3. 처리 완료 후 사용자에게 결과를 안내한다.

## 관리자 계정 보안 수칙

- 운영자 계정은 개인별로 분리한다.
- 비밀번호는 다른 서비스와 재사용하지 않는다.
- 공용 PC에서 관리자 로그인을 하지 않는다.
- 퇴사/계약 종료 즉시 관리자 권한을 회수한다.
- MFA 도입 전까지 SUPER_ADMIN 계정은 최소 인원만 보유한다.
