## 이번 적용 후보에 포함된 것

1. **공유와 권한:** 공개 글은 제목·요약·공통 이미지. 회원 전용 일반 글은 작성자가 선택한 경우에만 제목 표시. 기존 글은 기본 비공개. 문의·상담·비밀사연은 제목 공개 불가. 비회원은 로그인 안내를 거쳐 원문으로 돌아가며, 서버가 글·댓글·첨부파일 권한을 재확인한다.
2. **읽기와 쓰기:** PC의 휴대전화 테두리와 본문을 가리는 하단 메뉴 제거. 모바일 폭·한국어 줄바꿈·글자 크기 조정. 굵게·소제목·목록·인용·링크 편집과 작성/미리보기/게시 폭 일치.
3. **커뮤니티 운영:** 익명 고민·질문의 닉네임 보호와 운영자 답변 표시, 운영자의 신고·문의·회원 관리 대시보드.
4. **개발자 운영:** 개인정보를 가린 요청 오류, 서버·DB·배포·백업 진단 화면. 관리자 역할·서버 검증 MFA.
5. **비용·복구:** 현재 EC2와 6시간 백업 유지. 중복 빌드·미사용 이미지 관리, 격리 복원·경보 도구. 신규 RDS/서버는 포함하지 않는다.

## 확인한 테스트

- 공유 카드 HTML: PC Chrome·모바일 Chrome·iPhone WebKit 3개 통과.
- 새 글쓰기 선택·제목 수정 시 선택 해제·비회원 로그인 안내/본문 차단: 세 브라우저에서 9개 통과. 이 페이지의 글쓰기·로그인 화면은 실제 구현 웹 UI를 합성 데이터로 띄워 해당 테스트에서 캡처했다. 설치형 앱 WebView 검증은 별도다.
- 현재 검토 PR의 기존 전체 CI: 백엔드·프론트·실제 MySQL 8.4.10 Flyway/ORM·운영 스크립트·비밀정보 검사·CodeQL 통과. 새 브라우저 회귀 테스트가 추가된 최신 커밋의 CI는 별도 확인한다.

## 운영 반영 전 순서

1. AWS 관리자 연결을 복구하고 승인된 서울 리전 EC2/SSM 읽기 권한 세 개를 적용해 현재 청구·보안그룹·SSM·백업·경보·실행 이미지·Flyway 이력을 확인한다. 실제 MFA 키와 최초 등록 대상도 확인한다.
2. 스테이징에서 후보를 **백엔드·V47 검증 후 프론트엔드** 순서로 적용해 공유·로그인·일지·게시글·댓글·관리자 흐름을 검사한다.
3. 격리 복원, 암호화 데이터 복호화, 실물 iPhone/Android 앱 WebView와 카카오톡 공유 미리보기를 확인하고 스테이징을 중지한다.
4. 결과·남은 위험·배포 전 백업·직전 정상 이미지 복구 계획을 사용자에게 보여준 뒤 별도 운영 적용 승인을 받는다.

현재 두 PR은 초안이다. **운영 main 병합과 운영 배포는 하지 않았다.** 새 제목 공유 선택 기능 자체에 새 고정 AWS 자원은 필요하지 않으며, 모니터링·복구 키 비용과 실제 순절감은 현재 청구액 확인 전까지 확정할 수 없다.
