# 커뮤니티 글쓰기와 본문 표시

일반 글·비밀 사연·비공개 문의는 같은 본문 편집기를 사용한다. 기본은 기존 일반 텍스트
작성이며, `서식 편집 시작` 버튼으로 굵게·소제목·작은 제목·글머리/번호 목록·인용·링크를
사용할 수 있다. 되돌리기/다시 실행과 본문 미리보기를 제공한다. 이미 서식이 있는 글은
수정 시 서식 편집기로 열린다. 사진 첨부는 기존 기능을 유지한다.

작성창·미리보기·게시 화면은 같은 글꼴, 본문 폭(최대 430px), 줄 간격, 문단·목록·인용
스타일을 사용한다. 동일 기기와 화면 폭에서는 자동 줄바꿈이 같다. 다른 기기/폭/글자 크기에서는
자동 줄바꿈을 다시 계산한다. 사용자가 넣은 Enter·빈 줄은 보존한다. 긴 글은 편집창이 늘어나
내부 스크롤바가 본문 폭을 줄이지 않는다.

서식은 허용된 JSON 문서로 저장하고 기존 `content`에는 같은 내용을 일반 텍스트로 저장해
검색·기존 클라이언트와 호환된다. V45는 nullable `rich_content`만 추가하며 기존 글은 바꾸지
않는다. 서버는 문서 구조와 일반 텍스트 일치를 검증한다. 일반 텍스트 방식으로 수정하면
이전 서식을 제거해 서로 다른 본문이 표시되는 것을 방지한다.

HTML 입력/렌더링, 임의 이미지·스크립트·스타일은 허용하지 않는다. HTTP/HTTPS 링크만 허용하며
인증 정보가 포함된 주소와 다른 프로토콜은 차단한다. 새 탭 링크는 `noopener noreferrer
nofollow ugc`로 열린다. 화면은 React 텍스트 렌더링과 알려진 요소만 사용한다. 비공개 글의
본문을 볼 권한이 없으면 서식 문서도 전달하지 않는다.

서식 문서는 최대 200,000자, 3,000노드, 깊이 12, 일반 텍스트 UTF-8 60,000바이트를 허용한다.
기존 게시물 입력 검증도 함께 적용한다. 복잡도 제한을 넘은 초안은 삭제하지 않고 수정 안내와
함께 제출을 차단한다.

PC·모바일 테스트에서 각 글자의 줄 위치, 미리보기, 실제 API 요청의 서식 전송, 저장 후 표시,
재편집, 안전한 링크와 위험 링크 차단을 확인한다. 테스트용 API fixture는 실제 회원/게시물
데이터를 변경하지 않는다. AWS 스테이징에서 실제 DB 저장/조회 검증 후 운영에 배포한다.
