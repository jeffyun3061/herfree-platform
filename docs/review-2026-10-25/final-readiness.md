# 운영 적용 전 점검 기록 (2026-10-27 갱신)

## 판정

**현재 운영 배포 불가(NO-GO).** 이 브랜치는 검토 후보이며 운영 `main` 병합과 배포를 하지 않았다. 코드 검증 통과와 실제 서비스의 보안·복구 검증은 별개다. 기존 계획의 사용자 검토와 별도 운영 적용 승인도 아직 남아 있다.

## 이번 재점검에서 고친 것

* 글쓰기의 `비밀글로 작성`은 글 공개 범위를 바꾸지 않고 닉네임만 숨기는 기능이었다. `익명으로 작성`으로 고치고 공개 범위는 별도 설정을 따른다고 화면에 명시했다. 홈·메뉴의 `비공개 커뮤니티` 일괄 표현도 실제 공개 글이 있는 서비스에 맞게 고쳤다.
* 개인정보처리방침 초안의 `관리자 접근망/CIDR 제한` 보장을 삭제하고 후보 코드의 역할·MFA 통제에 맞췄다. 회원 전용 글 제목 공개 선택과 익명 고민 본문 공개 범위를 명시했다. 방침·웹 시행일과 신규 가입 동의 버전을 함께 갱신했다. **기존 회원 공지·필요한 재동의와 실제 배포일 기준 시행일은 운영·법률 검토 후 확정해야 한다.**
* 법적 문구 정합성 검사에 제목 공개와 익명 고민 공개 범위를 추가했다.

## 확인한 증적

* 프론트 ESLint 통과. 합성 OAuth 설정을 사용한 Next.js **Webpack** 운영 빌드 통과. 기본 Turbopack 빌드는 Windows 샌드박스의 하위 프로세스 생성 오류였고, 일반 샌드박스의 Webpack 정적 페이지 생성도 파일 권한 오류였다. 이 환경 제약을 우회한 빌드 결과와 GitHub Linux CI는 구분해서 기록한다.
* 합성 계정·글로 PC Chromium, 모바일 Chromium, iPhone WebKit에서 제목 공유 선택·제목 수정 재선택·비회원 로그인 화면·익명 선택과 실제 공개 범위 **12/12 통과**. 설치형 앱 WebView와 실제 메신저는 아직 미검증이다.
* `verify-legal-policy-alignment.ps1`의 코드·문안 정합성 검사 통과, 운영 사실 미평가 경고 1개. `-StrictOperationalFacts`와 `go-live-production.ps1 -DryRun`은 운영 주체·개인정보 담당자·메일 사업자·AWS 리전·국외 접근 관련 **12개 사실 미확인으로 차단**된다. 환경변수 입력만으로 법률상 적합성이 증명되는 것은 아니다.
* 스테이징 `develop` 커밋 `cef7263be423ec83eaa01ad74bb05849d7d928f1`의 [배포·보안 스캔·스모크·변경 기능 8개 검증](https://github.com/jeffyun3061/herfree-platform/actions/runs/40325055682)과 [호스트 사전 점검](https://github.com/jeffyun3061/herfree-platform/actions/runs/40326110043)은 통과했다. 복원 스크립트 수정 커밋 `f28e05c`의 CI는 아직 확인 전이다.
* 6시간 백업 실물·암호화·보관기간은 AWS에서 확인했다. 실제 격리 복원은 두 차례 모두 앱 검증 단계에서 실패했다. 두 번 모두 운영 DB는 변경하지 않았고, 두 번째는 스테이징 중지·원래 권한 복구·임시 디스크 삭제까지 자동 완료했다. 실패 원인 분류와 복원 성공 확인이 남아 있다.

## 운영 전 차단 항목과 담당

1. **운영자·개인정보 담당자:** 실제 운영 주체와 연락·권리 요청 처리 절차, 개인정보 보호책임자, 메일·분석 수탁자, 보유기간·국외 접근 사실을 증빙으로 확인한다. 개인정보처리방침 변경의 공지/재동의 필요성과 익명 건강 고민 공개 동의 방식, 운영자 답변의 의료광고·의료행위 표현을 한국 법률 전문가와 검토한다. 운영 담당자에게 의료 조언 금지/신고·삭제·침해 대응 교육을 진행한다.
2. **AWS 관리자:** 스테이징 조회 권한과 MFA 암호화 키는 확인했다. 관리자 권한 IAM 사용자와 실제 사이트 운영자 계정의 MFA를 본인 확인 후 등록하고, 경보 이메일 도달을 증명한다. 민감정보 키는 단순 교체하지 않는다.
3. **개발/운영:** 스테이징 기능 검증은 통과했다. 복원 앱 실패 원인을 개인정보를 가린 진단으로 확인하고, 격리 복원에서 암호화 데이터 복호화·핵심 기능·정리·중지를 성공시킨다. 실물 iPhone/Android 앱 WebView와 카카오톡 미리보기를 확인한다.
4. **배포 전:** 최종 SHA의 CI 통과, 운영 백업 성공, 현재 실행 이미지 digest와 직전 정상 이미지 3개, 정책 시행일·공지, 롤백 절차를 한 문서에서 확인하고 사용자에게 제시한다. 별도 운영 적용 승인을 받은 뒤에만 병합·배포한다.
