# 관리자 숨김 글 확인 — 검토와 운영 전제

기존 관리자 게시글·댓글 목록은 숨김 원글을 일반 상세 경로로 연결해 404가 발생할 수 있다. 관리자 검토 API는 현재 유효한 MODERATOR·ADMIN·SUPER_ADMIN만 호출할 수 있으며, 일반 상세와 공유 미리보기의 공개 범위를 바꾸지 않는다. 글 상태는 ACTIVE·HIDDEN만 허용하며 DELETED는 거부한다. 문의·상담도 기존 직원 열람 정책을 따른다. 응답은 no-store이고, 닉네임·계정 ID는 포함하지 않는다. 첨부는 기존 이미지 접근 검사를 거친다.

현재 main의 관리자 경로에는 사이트 MFA가 적용돼 있지 않다. 기존 `AdminAccessGateFilter`의 Bearer 토큰 경로는 IP 제한을 건너뛰고 역할 검사로 이어진다. 이 변경이 MFA나 네트워크 제한을 추가했다고 설명하지 않는다.

기존 `AdminAuditFilter`는 관리자 요청의 메서드·경로·상태를 기록하고 본문은 기록하지 않는다. 감사 저장이 실패하면 카운터와 오류 로그를 남기고 요청은 계속 진행한다. 따라서 감사 기록의 저장을 보장하거나 실패 시 접근을 차단한다고 설명할 수 없다. 사이트 MFA와 감사 실패 대응은 별도 검증 과제다.

사용자가 제보한 실제 글의 게시판·상태는 확인되지 않았다. 이 변경은 코드에서 재현되는 숨김 원글 404를 해결하며 모든 비공개 글 오류의 원인이라고 단정하지 않는다.
