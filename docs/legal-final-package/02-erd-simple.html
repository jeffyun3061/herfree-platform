Herfree 데이터 구조 (간단 ERD)

법률 검토용 요약 · 2026년 7월 · MySQL 8 (AWS RDS 서울)

실명·주민번호는 수집하지 않습니다. 이메일·닉네임·게시글·일지·OAuth 연결 ID가 주요 개인정보입니다.

1. 회원 · 인증

users이메일, 비밀번호(암호화), 역할, 계정상태(ACTIVE/SUSPENDED/DELETED)
user_profiles닉네임, 프로필 이미지, 자기소개
user_oauth_accounts카카오·네이버·구글 provider + provider_user_id
user_consent_agreements약관·처리방침·민감정보·14세·마케팅 동의 이력
health_statistics_consents건강정보 통계 선택 동의·철회 이력

2. 커뮤니티

boards게시판 종류(공지, 자유, 증상, 비공개 등)
posts제목, 본문, 작성자, 익명 여부, 상태(ACTIVE/HIDDEN/DELETED)
comments댓글, 작성자, 익명 여부
post_images게시글 첨부 사진 → S3 저장
reports신고 (게시글·댓글·회원)
reactions공감 등 반응

3. 개인 일지 (민감정보)

journal_records증상, 전조, 유발, 투약, 수면, 스트레스, 기분, 영양제·운동, 메모 — user_id 연결

4. 정보 콘텐츠 · 기타

contents칼럼 (운영자 등록)
videos유튜브 URL·메타정보
products외부 구매 링크 (1차 MVP)
app_event_logs행동 이벤트, IP·UA 해시 (원문 아님)
admin_audit_logs관리자 조작 감사

5. 관계 요약 (텍스트)

users 1 ── 1 user_profiles users 1 ── N user_oauth_accounts users 1 ── N user_consent_agreements / health_statistics_consents users 1 ── N journal_records ← 민감정보, 본인만 접근 users 1 ── N posts / comments posts 1 ── N post_images → AWS S3 boards 1 ── N posts

6. 저장 위치

실서비스 회원·일지·게시글 데이터: AWS RDS·S3 (ap-northeast-2, 서울)
