# ADR-023: 건강정보 공개 집계 경계

- 상태: 승인
- 날짜: 2026-07-29

## Context

소규모 서비스에서 당일 일지 작성 인원이나 작은 항목 수는 특정 회원의 건강 기록 존재를
추론하게 한다. 최근 500건만 조용히 집계하면 표본도 편향된다.

## Decision

모든 공개 건강 집계는 `HealthInsightPublicationPolicy`를 경유한다. 서로 다른 동의 회원
20명 이상, 항목별 5명 이상만 공개하고 비율은 5% 단위로 반올림한다. 기준 미달 시 정확한
현재 인원과 0건 항목을 반환하지 않는다. 500건을 초과하면 왜곡된 결과 대신 제공 불가로
응답한다. 동의 철회 회원은 최신 동의 조회와 no-store 응답으로 다음 집계부터 제외한다.

## Verification

임계값, 서로 다른 회원 판정, 셀 억제, 반올림, 501건 실패, 과거 미등록 코드 제외를 단위·
repository 통합 테스트로 검증한다.
