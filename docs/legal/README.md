# Herpfree 법률 문서 패키지

| 파일 | 용도 |
|---|---|
| `herfree-terms-of-service.md` | 앱 `/terms`에 반영한 이용약관의 검토용 원문 |
| `herfree-privacy-policy.md` | 앱 `/privacy`에 반영한 개인정보처리방침의 검토용 원문 |
| `legal-review-gates.md` | 사업자·수탁자·국외이전·동의 버전 확인 게이트 |
| `NOTICE-korean-privacy-terms.txt` | 참고 오픈소스 Apache-2.0 고지 |

앱 화면은 이 패키지와 동일한 핵심 문구를 사용합니다. 문구를 변경할 때는 앱 화면, 동의 버전(`UserConsentAgreementService`), 건강통계 정책 버전, 배포 환경의 실제 수탁자·보유기간을 함께 변경하고 테스트해야 합니다.

## 현재 공개 전 차단 사항

다음 정보가 채워지기 전에는 “법률적으로 완성된 최종본”으로 광고하거나 게시하지 마십시오.

- 운영자 법적 명칭·대표·사업장 주소·전화번호
- 개인정보 보호책임자 성명·직책·전화·주소
- 실제 메일·분석 수탁자와 국가·보유기간
- AWS 계약상 국외 접근·재위탁 여부
- 약관·처리방침 개정 시 기존 회원 재동의 정책
